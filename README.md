# Credit Default Risk - Expected Value Model

predicts the probabilty of default on consumer loan applications, 
then converts those probabilities into an approve/reject decision based on
expected profit rather than a fixed classification threshold.

**Data:** Home Credit Default Risk (Kaggle) — 307,511 applications
across 7 relational tables.

**Stack:** SQL for cross-table feature engineering, Python for modelling,
Power BI for the decision dashboard.

Status: in progress.
